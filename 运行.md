# nextTrade 服务器运维

## 日常更新代码

```bash
cd ~/nextTrade
git pull
docker compose -f docker-compose.prod.yml up -d --build
```

# 先停掉旧容器

docker compose -f docker-compose.prod.yml down api

## 单独重建某个服务（只重建 web 或 api）

```bash
# 只重建前端
docker compose -f docker-compose.prod.yml up -d --build web

# 只重建后端
docker compose -f docker-compose.prod.yml up -d --build api
```

## 数据库表结构变更（首次部署 & 改 schema.ts 后执行）

```bash
docker compose -f docker-compose.prod.yml exec api pnpm run db:push
```

## 监控运行状态

```bash
# 所有容器运行状态（CPU、内存、端口、运行时长）
docker compose -f docker-compose.prod.yml ps

# 全局资源占用
docker stats --no-stream

# 只看单个容器资源
docker stats --no-stream nexttrade-api-1 nexttrade-web-1

# 健康检查（API 接口）
curl -s http://localhost:3001/health
```

## 查看日志

```bash
# 所有服务
docker compose -f docker-compose.prod.yml logs -f

# 只看某个服务（实时跟踪）
docker compose -f docker-compose.prod.yml logs -f api
docker compose -f docker-compose.prod.yml logs -f web

# 只看最近 50 行（不跟踪）
docker compose -f docker-compose.prod.yml logs --tail=50 api

# 带时间戳
docker compose -f docker-compose.prod.yml logs -t -f
```

## 暂停 / 恢复

```bash
# 暂停所有（数据保留）
docker compose -f docker-compose.prod.yml down

# 恢复所有
docker compose -f docker-compose.prod.yml up -d

# 只停 web 和 api，数据库继续运行
docker compose -f docker-compose.prod.yml stop web api

# 恢复 web 和 api
docker compose -f docker-compose.prod.yml start web api

# 完全清理（⚠️ 删数据库）
docker compose -f docker-compose.prod.yml down -v
```
