# nextTrade 服务器运维

## 日常更新代码

```bash
cd ~/nextTrade
git pull
docker compose -f docker-compose.prod.yml up -d --build
```

## 单独重建某个服务（只重建 web 或 api）

```bash
# 只重建前端
docker compose -f docker-compose.prod.yml up -d --build web

# 只重建后端
docker compose -f docker-compose.prod.yml up -d --build api
```

## 数据库表结构变更（首次部署 & 改 schema.ts 后执行）

```bash
docker compose -f docker-compose.prod.yml exec api pnpm run db:push
```

## 查看日志

```bash
# 所有服务
docker compose -f docker-compose.prod.yml logs -f

# 只看某个服务
docker compose -f docker-compose.prod.yml logs -f api
docker compose -f docker-compose.prod.yml logs -f web
```

## 暂停 / 恢复

```bash
# 暂停所有（数据保留）
docker compose -f docker-compose.prod.yml down

# 恢复所有
docker compose -f docker-compose.prod.yml up -d

# 只停 web 和 api，数据库继续运行
docker compose -f docker-compose.prod.yml stop web api

# 恢复 web 和 api
docker compose -f docker-compose.prod.yml start web api

# 完全清理（⚠️ 删数据库）
docker compose -f docker-compose.prod.yml down -v
```
